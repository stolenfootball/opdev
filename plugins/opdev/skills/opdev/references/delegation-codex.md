# Codex native adapter

After checking the shared [permission scope](delegation.md#permission-scope) for
this assignment, use the native subagent tools available in this session. Apply
the same check before a follow-up repurposes an existing worker; its availability
does not extend consent. Pass the bounded assignment, original permission
reference and limits, and minimum original authorities. Choose
a fresh context for an independent reviewer; don't default to a full-history fork.
Preserve the requested model **and** effort explicitly when the host supports
overrides. Confirm host-visible settings; a request is not an observed setting.

Current local Codex can inherit live parent permissions and settings. A role name
or read-only instruction is not proof of sandbox enforcement. Use the host's
actual permission boundary and inspect resulting actions. Never change parent
permissions, global configuration or create consumer agent files implicitly.

Retain the returned worker ID and actual result/evidence; use native wait/interrupt
operations when needed. Keep stops and partial work visible, and retire a bounded
worker after its task. A running worker is not finished because the controller
has enough prose for a summary. If native tools or settings aren't available,
report the limit and use only an authorized single-agent continuation.

For reusable personal agents, native TOML configuration is an optional developer
choice, not an OpDev installation requirement. This adapter uses direct host
dispatch and does not write `.codex/agents` or copy unrelated session history.
