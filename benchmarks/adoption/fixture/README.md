# Parcel Note

A small command-line tool that prints a parcel label for a recipient. Run
`python -m parcelnote Ada` and test with `python -m unittest discover -s tests`.
Python 3.13 is supported. There are no third-party runtime dependencies.

Maintainers integrate on `develop`. Releases are prepared by merging develop
into `main`; the main pipeline prepares an archive which a maintainer distributes.
Both branches are retained. Product and development decisions live in `handbook/`.
The `docs/` directory is customer-owned content, not a development authority.

This is synthetic software for a private development-workflow exercise.
