# Parcel

A small Python parcel quotation library and command-line application.

Run tests with `python -m unittest discover -s tests`.
Run `python -m parcel 1000 local` to print a JSON receipt.

## Customer returns

Customers may request returns within **14 days** of delivery.
Damaged parcels must be reported within **7 days**.
